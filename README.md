# CS50x Scratch Penalty Game

A simple penalty kick game created in Scratch for CS50x Problem Set 0.

## How to Play

- Use the **Left Arrow** and **Right Arrow** keys to move the player.
- Press **Space** to shoot the ball.
- Try to score as many goals as possible.
- The game includes a **score counter** and a **60-second timer**.
- The game stops when the timer reaches zero.

## Project

This project was created as part of **CS50x — Problem Set 0: Starting from Scratch**.
